 Payroll Management System (OSDBMS Project)

 📌 Project Description
This project is developed as part of the Open Source Database Management System (OSDBMS) subject.  
It is a Payroll Management System developed using MySQL.

 🎯 Objectives
- To design a structured database system
- To implement SQL queries for data management
- To ensure data integrity using constraints
- To gain hands-on experience with MySQL

 🗂 Database Structure
The system contains the following tables:
- Department
- Employee
- Salary
- Payroll

 💻 Technologies Used
- MySQL Workbench
- SQL
- GitHub

 📊 Features
- Insert employee and department records
- Generate payroll reports
- Perform JOIN, GROUP BY, HAVING, Subqueries
- Create Views for reporting
